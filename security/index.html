Sample workspace

Controls in the current workflow.

Browser-local records

Sample edits, review reports and activity remain in this browser. Reset removes workspace changes and the sample session.

Explicit data submission

Prepared cases run locally. Connected analysis sends only entered inputs to the service address specified by the operator.

Human review

Reviewers can trace findings to a source, retain a dated report and record watering outcomes. Pump operation stays with the irrigation team.

Hosted workspace

Access follows membership.

Email and password

Supabase Auth verifies email addresses, checks passwords and manages sessions.

Workspace permissions

Postgres checks membership for each zone record. Operators can edit records and viewers can read them.

Recorded changes

Zone changes create activity entries with a timestamp and the signed-in account.

Azure deployment option

Planned controls for production data.

ControlImplementation design
Identity and permissionsMicrosoft Entra ID and role-based authorization for operators, reviewers and administrators. Use managed identities for service-to-service access.
Storage isolationTenant-scoped Blob containers, encryption settings and retention policies. Validate separation and access requirements before data ingestion.
Keys and networkAzure Key Vault for secrets and certificates, TLS 1.2+ and Azure Private Link for supported services.
Operational monitoringAzure Monitor and Application Insights to measure service health and errors. Defender for Cloud for resource security posture.
Audit retentionRoute protected audit records to immutable storage under a defined retention period.
Scope

Before connecting organizational data.

Does sample access create an account?

Sample access opens a public browser-local workspace. Organization access requires a configured identity provider and tenant permissions.

Where are model credentials stored?

Provider credentials are configured on the server running the included adapter. The static pages contain no provider secrets.

How do I clear sample workspace data?

Use Reset demo data under Settings. Downloads and material previously sent through external services are managed separately.

The problem

Irrigation demand changes faster than the schedule.

A new weather forecast, a falling moisture reading or a shared pump limit can change the order of the next watering cycle.

See the solution
Daily decisions

The same water has to serve multiple zones.

When readings, weather and flow limits live in different places, an operator has to reconcile them before setting the next cycle.

  • An isolated sensor reading can hide a failing probe.
  • Several zones may need the same pump window.
  • The plan and the flow-meter record need to be compared.
The problem

A fixed schedule misses changing conditions.

A shared pump puts each zone in competition for the same supply. Rill compares current conditions and pump capacity so the operator can review the next cycle as one plan.
